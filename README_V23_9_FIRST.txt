ITTR v23.9.0 — READ FIRST

1. Deploy this package over the SAME GitHub/Railway service and PostgreSQL database.
2. In Railway → Web Service → Variables add: FMCSA_WEBKEY=<your official FMCSA developer WebKey>
3. Redeploy.
4. Confirm the green banner shows ITTR v23.9.0 and backend 23.9.0.
5. Open Customers → Add Customer or Edit Customer.
6. Type a USDOT number. The lookup runs automatically after a short pause, or click Lookup FMCSA.

No database reset. Do not expose the WebKey in GitHub, screenshots, or chat.
