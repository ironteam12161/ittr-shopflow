3. Scroll to top and bottom inside work order modal. Nothing may sit over content.

HELPER MECHANIC

2. Select another mechanic. Helper should see same unit on their phone after cloud refresh.
3. Primary starts Task A. Helper must see Task A as Working by Primary and cannot pause/complete it.
4. Helper starts Task B at the same time. This must be allowed.
5. Helper pauses Task B; only Helper can pause/complete that running session.
6. Primary or Helper can add a Finding; R2 photo upload must still work for Helper.
7. Resume/complete tasks with different mechanics and verify task timeline shows mechanic name on every session.
8. Complete work order only after every task has a final outcome and no task is running.
9. Open completed work order. Mechanic Work Summary must list each mechanic, tasks worked, and labor time.
10. Admin can remove a helper only when that helper has no running task.

REGRESSION

- Findings approvals must still add/hold/decline tasks.
