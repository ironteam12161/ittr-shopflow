# ITTR ShopFlow v24.17.9

Adds inventory selling-price autofill and per-part markup percentage controls to invoice rows.

- Selecting an inventory part fills stored Cost and Selling Price.
- Markup % is derived from Cost and Selling Price.
- Editing Markup recalculates Selling Price.
- Editing Selling Price recalculates effective Markup.
- No database reset or destructive migration required.
