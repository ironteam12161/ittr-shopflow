Labor rates
- Presets: New client $115/hr, Our client $110/hr, Old client $100/hr, Owner $60/hr, Custom.
- Preset and numeric amount are one combined control.
- New labor operations copy Labor 1's current rate.
- Changing Labor 2/3/4 does NOT change the default for later labor; Labor 1 remains authoritative.
- If no Labor 1 exists, new labor uses the customer's stored default_labor_rate when available.

Parts
- Part # and description are one unified search area.
- Either field searches the existing fullbay_import_parts inventory catalog.
- Results show part number, full description, sell price and available quantity.
- Selecting a result fills part number, description, sell price, internal cost and sell-taxable state.
- Adding a child part first persists every visible invoice line and header so unsaved labor/rates are not discarded.

Illinois tax
- Server-side lookup reads the official IDOR current jurisdiction machine-readable sales-tax file.
- Cached for six hours; frontend never fetches or exposes an external API key.
- Defaults to SHOP_TAX_CITY / SHOP_TAX_COUNTY; fallback is Matteson / Cook.
- If IDOR marks a jurisdiction for address override, the UI warns the user to verify with the official Tax Rate Finder.
- Manual tax-rate edits update totals live.
- Shop supplies and environmental/other fee each have explicit taxable switches.
- Invoice discount is allocated proportionally when determining taxable base.
- Labor remains non-taxable by default; inventory parts use their sell_taxable value.

Database / route safety
- Added columns with ADD COLUMN IF NOT EXISTS only; no destructive reset.
- customer_invoices: shop_supplies_taxable, environmental_fee_taxable, tax_source, tax_effective_date.
- Server recalculates authoritative subtotal/tax/total/balance on save.
- Existing v23.7.1 inventory import SQL fix remains present.
