# New features — setup (v24.52 – v24.56)

Everything works without extra setup except where a Railway variable is listed.

| Feature | Where | Railway variables |
|---|---|---|
| Change own password, sign out other devices | 🔒 Password (top bar) | — |
| 2-step login (authenticator app) | 🔒 Password → Turn on 2-step login | `ITTR_RESET_2FA=<username>` only as a last resort if a phone and its recovery codes are lost (remove it after the restart) |
| Full backup | 🔒 Password → Download backup (owner) | — |
| Deleted work orders (recycle bin, 90 days) | 🔒 Password → Open recycle bin (owner) | — |
| Canned jobs | "+ Canned job" on estimates, invoices, work orders | — |
| Online estimate approval, inspection share | "📤 Send for approval" (estimate), "📤 Send to customer" (inspection) | `APP_PUBLIC_URL` (e.g. `https://shop.ironttr.com`) so links point to the public address |
| Fleet customer portal | Customer profile → "📤 Portal link" | `APP_PUBLIC_URL` |
| Texting customers (two-way) | 💬 Texts (top bar), customer profile → 💬 Text | `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM` (+1… number) or `TWILIO_MESSAGING_SERVICE_SID`. In Twilio, set the number's "A message comes in" webhook to `<APP_PUBLIC_URL>/api/sms/inbound` (HTTP POST). US numbers need A2P 10DLC registration in Twilio before texts are delivered. |
| Purchase orders | Money → Orders | — (emailing a PO uses the connected shop email) |
| Warranty & comebacks | Reports → Team → Comebacks; notice on the work order vehicle card | — (terms set by the owner in the Comebacks report) |
| Error alerts | — | `ALERT_WEBHOOK_URL` = a Slack / Discord / Microsoft Teams incoming-webhook URL |

Also recommended: an uptime monitor (e.g. UptimeRobot, free) on `<APP_PUBLIC_URL>/api/health`,
Railway Postgres automatic backups turned on, and GitHub → Settings → Branches → require the **audit** check on `main`.
