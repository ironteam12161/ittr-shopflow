ITTR v24.5.2 — Responsive UI Stability Audit
Date: 2026-09-12

Primary regression fixed
- Mobile "More" bottom sheet had no desktop default CSS, so its raw HTML rendered as normal page content on desktop.
- Added desktop-safe hidden defaults for .mobileMoreSheet and .mobileMoreBtn.
- Added explicit desktop breakpoint enforcement so mobile navigation chrome cannot leak into desktop views.
- openMobileMore() now no-ops on desktop.
- If the viewport grows above the mobile breakpoint while the sheet is open (rotation/resize/devtools), the sheet closes automatically.

Responsive/navigation hardening
- Desktop: mobile bottom nav + mobile More sheet forcibly hidden.
- Mobile: More sheet remains an overlay/bottom sheet only, above normal application content.
- More sheet uses one/two-column responsive layout and safe-area padding.
- Existing nested modal z-index fixes for barcode scanner, inventory count, task pause/outcome/helpers remain preserved.
- Modal overscroll containment retained/improved.

Performance/interaction polish
- Mobile chrome resize work is requestAnimationFrame-throttled to reduce repeated layout work during browser resize, keyboard animation, and orientation changes.
- Focus-visible treatment added for keyboard/accessibility navigation.
- Small interaction transitions added without heavy animations.
- Existing cloud refresh intervals and core business logic were intentionally left unchanged.
